### Cancellation boundaries

Owners can cancel before dispatch. Workers can cancel pending-payment or paid orders. Payment history stays intact, and late provider confirmations do not reopen fulfilment or re-reserve stock. Refunds are handled separately. Orders without a committed website reservation movement receive no automatic restock, including historical orders whose deduction cannot be proven. Review cancellations recorded before this change separately. The shared schema blocks a shoe’s conversion to size tracking while its colour-only website reservation is open. If a historical conversion already obscured the original variant, cancellation fails atomically for manual reconciliation.
