# Pedigree Leather: project context

Read `AGENTS.md` first. It was generated by create-next-app and holds Next.js-specific rules for this repo. Follow it. This file adds the project brief on top of it.

## What we are building
An ecommerce website for **Pedigree Leather**, a leather goods shop in Nairobi, Kenya. They sell shoes and handbags. **Launch scope is handbags only.** Shoes come later, so the data model must already support them.

Tagline: "Luxury • Style • Comfort". Currency: **KES** (format like `KES 4,500`). Most shoppers are on phones, so design **mobile-first**.

## Stack (do not swap or add major dependencies without asking)
- Next.js (App Router), TypeScript (strict), Tailwind CSS, pnpm
- **Motion** (the `motion` package, formerly Framer Motion) for animation
- Later phases: Supabase (database, auth, image storage), Paystack (M-Pesa + card), WhatsApp confirmations
- Hosting: GitHub + Vercel

## Brand and look
- Warm leather **brown** as the main accent (buttons, prices, links). Approximately `#7F4F28`. This is an estimate from the logo, so keep it in ONE place as a design token and make it easy to change.
- **Charcoal** (approximately `#474747`) for text, header and footer.
- White or soft cream backgrounds so product photos stand out.
- A small red/rust badge color for discounts only.
- Fonts via `next/font`: an elegant serif for headings only (for example Cormorant Garamond or Fraunces) and a clean sans for body text (for example Manrope or DM Sans). Avoid Arial and Inter.
- Feel: quiet, spacious, high-end. Large product images, generous spacing, few distractions.
- Logo is not ready yet. Use the text "Pedigree Leather" in the header as a placeholder, in a component that is easy to swap for an SVG.
- Use the project's installed design/animation skills if available.

## Product viewer (the most important feature)
Each **product** has several **colors**. Each color has its own set of **views** (photo angles): `front`, `left`, `right`, `top`, `back`. Some products may have fewer angles.

- The user drags or swipes through the angles of the current color. Also provide thumbnails and left/right buttons.
- Below the viewer is a row of color swatches. Selecting a swatch switches the displayed bag to that color and **keeps the current angle**.
- Real photos are not available yet. Until then each view renders as a **placeholder block filled with the color's hex**, with the angle name shown on it. Use a fixed aspect ratio of 4:5 so nothing shifts when real images arrive. A view with no `src` shows the placeholder.

## Card animation
Product cards open on click into a detail view and close back smoothly:
- Use Motion shared layout animation (`layoutId`) so the card expands from its own position and returns to it.
- Spring transition, animate only transform and opacity. It must feel smooth on a mid-range phone.
- Dim the background while open. Close on backdrop click, the Esc key, and a visible close button. Trap focus inside while open and restore focus on close.
- Respect `prefers-reduced-motion` by using a simple fade.

## Data model (typed in `lib/types.ts`)
```ts
type Angle = "front" | "left" | "right" | "top" | "back";

type ProductColor = {
  id: string;
  name: string;            // "Tan"
  hex: string;             // swatch + placeholder fill
  stock: number;           // per color
  views: { angle: Angle; src?: string }[];
};

type Product = {
  id: string;
  slug: string;
  name: string;
  description: string;
  category: "bag" | "shoe";
  material?: string;
  dimensionsCm?: { height: number; width: number; depth: number };
  priceKes: number;
  discount?: { type: "percent" | "fixed"; value: number; startsAt?: string; endsAt?: string };
  colors: ProductColor[];
  sizes?: string[];        // for shoes later
};
```
Start with a local `data/products.ts` holding 4 sample bags with 2 to 4 colors each. Later the same shape moves to Supabase, so keep all data access behind functions in `lib/products.ts` (for example `getProducts()`, `getProductBySlug()`), and never read the sample file directly from components.

10. WhatsApp order confirmations, privacy and returns pages, SEO, polish
